System Architecture & Documentation

Overview of KPRM2 Background Verification & Case Management Platform (Go Version)

High Performance Go Engine

This standalone Go implementation of KPRM2 provides native speed, memory efficiency, concurrent goroutine request handling, and strict type safety while preserving 100% interoperability with the existing MySQL database, uploaded assets, and frontend UI templates.

Two-Way Bcrypt Auth

Transparently verifies PHP $2y$ password hashes and produces compatible hashes for both systems.

Native Excel MIS Export

Streams styled, dark-bordered Excel spreadsheets using Excelize with zero external runtime dependencies.

WhatsApp Suite

Direct GreenAPI integration with phone masking, multi-instance switching, QR scanner, and automated event triggers.

Financial Matrix Engine

10-parameter comparative audit with Indian currency notation (₹ 10,00,000) and automated variance calculation.
